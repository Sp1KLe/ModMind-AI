# ModMind AI

Бесплатный помощник для создания Minecraft-модпаков по описанию.

## Архитектура
- Backend: FastAPI (Python).
- Каталог и файлы: публичный Modrinth API.
- Подбор: бесплатный поиск по описанию и фильтры совместимости; платный AI API не требуется.
- Сборка: сервер формирует ZIP с настоящими файлами модов.
- Клиент: адаптивный веб-интерфейс; позже можно подключить Android-приложение.

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
Откройте http://127.0.0.1:8000

## API
- `GET /api/health`
- `GET /api/search?query=...&minecraft_version=1.20.1&loader=fabric`
- `POST /api/build` — JSON: `{"name":"My pack","minecraft_version":"1.20.1","loader":"fabric","project_ids":["sodium","lithium"]}`; возвращает ZIP.

## Важно
- Это начальная MVP-версия. Подбор по описанию пока использует поиск Modrinth, а не генеративную языковую модель.
- Если обязательная зависимость не выбрана, сборка остановится и сообщит об этом.
- Размер серверной сборки ограничен 450 МБ.
- ZIP содержит файлы модов в папке `mods/` и `manifest.json`. Импортируйте его в совместимый лаунчер или распакуйте согласно его требованиям.
- Бесплатный хостинг может иметь ограничения на время работы, память и размер временных файлов.
- Не храните секреты и токены в репозитории.
