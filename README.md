# ModMind AI

Бесплатный помощник для создания Minecraft-модпаков по описанию.

## Возможности
- Gemini AI превращает описание модпака в точные поисковые запросы (если настроен серверный ключ).
- Бесплатный резервный поиск по ключевым словам работает без Gemini.
- Поиск реальных модов и метаданных в Modrinth.
- Выбор версии Minecraft и загрузчика: Fabric, Forge, NeoForge или Quilt.
- Проверка совместимых версий перед сборкой.
- Автоматическое рекурсивное добавление обязательных зависимостей.
- Скачивание настоящих файлов модов и сборка ZIP: папка mods плюс manifest.json.
- Ограничение сборки: до 80 проектов и 450 МБ файлов.

## Безопасная настройка Gemini
1. Создайте API-ключ в Google AI Studio.
2. На сервере задайте переменную окружения `GEMINI_API_KEY` со значением ключа.
3. При необходимости задайте `GEMINI_MODEL` (по умолчанию `gemini-3.8-flash`).
4. Перезапустите сервер.

**Не вставляйте ключ в `web/index.html`, Android-клиент, GitHub или публичные файлы.** Для публичного развёртывания используйте секреты платформы-хостинга. Если ключ был опубликован, отзовите его и выпустите новый.

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export GEMINI_API_KEY="YOUR_KEY"  # необязательно: без ключа работает резервный поиск
uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000

## API
- GET /api/health
- POST /api/plan — превращает описание в поисковые запросы.
- GET /api/search?query=...&minecraft_version=1.20.1&loader=fabric
- POST /api/build — JSON с name, minecraft_version, loader и массивом project_ids; возвращает ZIP.

## Ограничения
- Gemini не выбирает и не скачивает файлы напрямую: он формирует поисковые запросы. Существование модов, совместимость и загрузки проверяются через Modrinth.
- Бесплатные лимиты Gemini зависят от модели, региона и текущих правил Google; отсутствие платного тарифа не гарантирует неограниченный доступ.
- При недоступности Gemini автоматически включается обычный поиск.
- ZIP содержит сами JAR-файлы в папке mods и манифест ModMind. Это обычный архив, а не импортируемый .mrpack.
- Бесплатный хостинг может ограничивать время работы, память и временное хранилище.
