# ModMind AI

Бесплатный помощник для создания Minecraft-модпаков по описанию.

## Возможности
- Поиск модов в каталоге Modrinth по текстовому описанию.
- Выбор версии Minecraft и загрузчика: Fabric, Forge, NeoForge или Quilt.
- Проверка совместимых версий перед сборкой.
- Автоматическое рекурсивное добавление обязательных зависимостей.
- Скачивание настоящих файлов модов и сборка ZIP: папка mods плюс manifest.json.
- Ограничение сборки: до 80 проектов и 450 МБ файлов.

## Архитектура
- Backend: FastAPI.
- Каталог и файлы: публичный Modrinth API.
- Подбор: бесплатный поиск и фильтры совместимости; платный AI API не требуется.
- Клиент: адаптивный веб-интерфейс.

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000

## API
- GET /api/health
- GET /api/search?query=...&minecraft_version=1.20.1&loader=fabric
- POST /api/build — JSON с name, minecraft_version, loader и массивом project_ids; возвращает ZIP.

## Важно
- Сейчас подбор использует поиск Modrinth и ключевые слова, а не генеративную языковую модель.
- Обязательные зависимости разрешаются автоматически. Для каждой проверяется совместимая версия под выбранную версию игры и загрузчик.
- Если обязательная зависимость не имеет совместимой версии, сборка сообщит об ошибке.
- ZIP содержит сами JAR-файлы в папке mods и манифест ModMind. Это обычный архив, а не импортируемый .mrpack.
- Бесплатный хостинг может ограничивать время работы, память и временное хранилище.
- Не храните секреты и токены в репозитории.
